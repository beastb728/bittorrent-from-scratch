# Torrent Parser (Phase 2)

This phase focuses on understanding and implementing Bencode parsing for `.torrent` files.

Implemented:

* String parsing
* Integer parsing
* List parsing
* Dictionary parsing
* Recursive `decode()` function
* Parsing real-world torrent files

Tested using:

* Ubuntu 26.04 Desktop torrent

Concepts explored:

* Bencode
* Torrent metadata
* SHA-1 piece hashes
* Piece lengths
* Trackers
* Nested data structures
